📡

Service Worker

Caches all your static assets (HTML, CSS, JS, images) on first visit. Subsequent loads are instant — even offline.

🧠

ADE — Auto Discovery

Watches every fetch() and XHR call during online sessions. Learns your API routes automatically.

📋

POSA — Op Journal

Every user action offline is stored in IndexedDB as a signed operation with HLC timestamp. Nothing is lost.

🔄

Sync Router

On reconnect, queued ops are routed: ASG-apps batch to /api/v1/posa/sync, 3rd-party sites replay to their own endpoints.

✅

Reconciliation

After replay, fetches authoritative server state and replaces provisional local data. Your UI always shows truth.

⚔️

Conflict Resolution

HLC (Hybrid Logical Clocks) ensure multi-device operations merge deterministically using Last-Write-Wins or custom strategy.
